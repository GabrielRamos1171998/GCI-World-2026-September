## 📚 About the Project

This repository is being developed as a personal learning library during my studies in data science, machine learning and artificial intelligence.

The objective is to transform study materials, programming exercises and technical concepts into an organized and reusable knowledge base.

The library combines:

- Explanations
- Code examples
- Data analysis
- Machine learning experiments
- Technical terminology
- Multilingual definitions
- Interactive Python components
- Practical exercises
